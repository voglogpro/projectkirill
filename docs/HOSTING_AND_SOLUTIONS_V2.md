# Форматы запуска и готовые решения KIRA

Обновление 5 сентября 2026. Новая модель действует в UI, API и runtime, а не только в подписях карточек.

| План | Месяц | Запуск |
| --- | ---: | --- |
| Solo | 350 ₽ | Один текстовый бот; отдельный сайт также остаётся на этом плане |
| Trio | 650 ₽ | До трёх текстовых ботов, без Mini App |
| Studio | 650 ₽ | Один бот + Mini App, сайт можно добавить без доплаты |

Все четыре редактора и локальные предпросмотры бесплатны. Тип проекта `bot`, `bot-app`, `bot-app-site`, `site` хранится на сервере. В аккаунте действует один план: смена плана заменяет предыдущие ограничения, а не добавляет ещё один пакет. Отдельный сайт оставлен за 350 ₽, поскольку для него пользователь не назначил новую цену.

## Готовые решения

18 решений вместо 10; каждое имеет несколько связанных маршрутов, вопросы, валидацию ввода и результат с ответами клиента. Все 18 иллюстраций различаются по задаче: календарь, товары, посылка, урок, дом, резюме, инструмент, камера и т. д. Четыре конструктора показаны через бота, телефон, браузер и связку устройств. Сохранены Onest/Unbounded, тёмная палитра KIRA; смысловые акценты фиолетовый/голубой/зелёный/янтарный.

Каталог показывает результат, фактическое число узлов и раскрываемый список настройки. Сценарии можно проверить в симуляторе и открыть отдельной бесплатной копией, не меняя облачный проект. Новые направления: недвижимость, рекрутинг, ремонт, ресторан, фитнес, консультации, фотограф и адаптация сотрудников.

Это готовые анкеты и диалоги, а не неподключённые интеграции: подтверждение записей/заказов и обработку заявок выполняет команда клиента. Нет обещаний автоматических календарей, оплат, CRM, проверки уроков или рассылок. Текстовые боты работают с настоящим Telegram runtime после публикации.

## Миграция и публикация

- Новая миграция `008_product_kits.sql` добавляет формат и план Studio. Штатный runner автоматически находит её при старте; ручного изменения Neon в этой задаче не было.
- Старые проекты невозможно надёжно классифицировать по существующим данным: они сохраняют полный формат и уже оплаченный доступ только до конца текущего оплаченного периода. Суммы, платежи и подписки не переписываются. Дальше применяется новая модель.
- Формат можно изменить в настройках проекта без удаления страниц и сценария. Для активного проекта есть подтверждение. После смены формата используйте «Обновить подключение» → «Обновить токен и кнопку меню»: сервер очистит или установит меню Telegram. До обновления старая кнопка может остаться в Telegram, но неподходящий тариф уже не даёт доступа к Mini App.
- Публикация страниц, публикация сценария, подключение бота, публичные данные и worker проверяют возможности тарифа. Trio не предоставляет Mini App. Дополнительные проекты после снижения лимита не продолжают бесконтрольно работать.
- `/s/` запрашивает публичный манифест с `surface=site`; текстовые проекты не имеют публичного Mini App. Данные опубликованных приложений больше не кешируются публично после завершения доступа.
- Отдельный сайт по-прежнему подключается через Telegram-бота. Отправка публичной формы сохраняет прежнее требование Telegram initData — анонимные веб-формы не добавлялись.

## Проверки

На главной и в `/hub` каталог по умолчанию работает как зацикленная лента:
центральная карточка чёткая, две соседние слегка размыты. Наведение мыши,
касание или фокус клавиатуры выделяют соседнюю карточку. На телефоне центральная
карточка занимает основную ширину, по краям видны части соседних. Стрелки и горизонтальный свайп
переключают решения по кругу; вертикальный жест оставлен для прокрутки страницы.
«Посмотреть все» раскрывает всю отфильтрованную сетку без размытия, «Вернуть ленту» возвращает
на прежнюю позицию. Поиск и смена категории начинают новую ленту с первой карточки.
Автоматического перелистывания нет. Регрессия проверяет доступность всех 18 решений,
переходы через оба края, раскрытие/сворачивание и мобильные жесты на обеих страницах.

Название вкладки: `KIRA - Конструктор ботов миниаппов сайтов`; подпись к логотипу
обновлена на главной и в hub. Краткая стоимость запуска поднята к началу страницы,
подробные тарифы остаются по якорю. Суммы 350/650 ₽ и правила биллинга не менялись.

`npm.cmd test`, `npm.cmd run build`, `node tools/preview/build.mjs`.

Браузерные регрессии (Playwright, локальный Vite на 5174, все API/платежи замоканы):

```powershell
node tools/qa-start-hub.mjs
node tools/qa-flow-editor.mjs
node tools/qa-pricing.mjs
```

Если Playwright установлен вне workspace, задайте `KIRA_BROWSER_MODULE` полным путём к модулю. Проверены 1440/390/320 px, 18 разных обложек, поиск/категории/настройка, симулятор, сохранение бесплатных копий и отсутствие изменений исходного проекта. Тарифные проверки включают запрет Mini App на оплаченном Trio и разрешённую последовательность публикации на Studio.

Миграции и SQL проверены отдельно в изолированной PGlite: все восемь миграций, матрица планов/форматов, льготный оплаченный период, истечение доступа, downgrade, лимиты и SQL webhook/worker. Повтор: `KIRA_PGLITE_MODULE=<путь к @electric-sql/pglite>` и `node test/product-kit-sql.mjs`. Живая Neon не используется.

Остаётся предупреждение Vite о размере общего JS кабинета; Mini App сохраняет отдельный лёгкий бандл. Стенд пересобирается локально, внешний Claude-артефакт не публиковался. BotHost деплоит владелец.
