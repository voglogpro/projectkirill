# Редактор сценариев: ПК и телефон

Один документ сценария используется на всех устройствах. Режим интерфейса выбирается по ширине окна: до 860 px — мобильный. Палитра KIRA и существующие видео сохранены.

## ПК

- Тяните блоки по сетке; выделение рамкой доступно в режиме стрелки.
- Режим руки, пробел или средняя кнопка мыши перемещают холст.
- Соедините выход справа со входом сверху. У кнопок и условий отдельные выходы.
- Нажмите на линию: её концы подсветятся. Перенесите начало или конец на другой блок.
- Один выход ведёт только в один шаг. Новая связь на занятом выходе заменяет прежнюю; отмена восстанавливает обе затронутые связи.
- Отпускание линии в пустом месте не удаляет связь. Для удаления есть кнопка и Delete/Backspace.
- Отмена/повтор — кнопками или Ctrl/⌘+Z, Ctrl/⌘+Shift+Z. История ограничена 50 действиями текущего сеанса редактора.

## Телефон

- Нажмите на блок. «Содержимое» редактирует текст и кнопки, «Связи» выбирает следующий шаг для каждого выхода.
- «Не соединено» удаляет выбранный переход.
- По умолчанию перетаскивание перемещает холст; два пальца меняют масштаб.
- «Двигать блоки» включает перетаскивание карточек. «Готово» возвращает режим редактирования.
- Нижняя панель добавляет шаги; настройки открываются снизу. Мини-карта скрыта.

## Сохранение и ограничения

Перенос блока сохраняется после завершения жеста. Связи и свойства сохраняются с задержкой 900 мс, облачные записи выполняются последовательно с актуальной ревизией. Выход через кнопку кабинета и запуск дожидаются сохранения. Локальная копия остаётся в localStorage. Undo не переносится между устройствами и не сохраняется после перезагрузки.

Удаление кнопки/условия удаляет осиротевшие линии. Нельзя соединить блок сам с собой, направить связь в команду, удалить `/start` или создать более 10 кнопок в сообщении. Возврат к другому предыдущему шагу разрешён.

## Проверка

- `npm run typecheck`, `npm test`, `npm run build`.
- `node tools/preview/build.mjs` собирает автономный `preview/index.html`, включая оба формата видео. Скрипт работает и в Windows.
- `node tools/qa-flow-editor.mjs` запускает Playwright против локального веб-сервера на `http://127.0.0.1:5174`. URL можно задать через `KIRA_QA_URL`; путь к отдельно установленному модулю Playwright — через `KIRA_BROWSER_MODULE`.
- Браузерный прогон проверяет перенос обоих концов линии, замену занятого выхода, некорректный сброс, удаление/отмену, защиту `/start`, сохранение координат, мобильные связи и touch-перетаскивание, загрузку видео и смену формата при resize.
- Облачные запросы в браузерном тесте перехвачены локальными HTTP-моками: проверяются очередность ревизий, отсутствие бесконечного autosave и сохранение перед публикацией. Реальные Neon, Telegram и BotHost не затрагиваются.
- Скриншоты проверки: `preview/qa/`. Generated preview и скриншоты не входят в Git. Этот прогон не заменяет тестирование реального Telegram на физическом телефоне.

Техническая основа переноса связей: [React Flow — Reconnect Edge](https://reactflow.dev/examples/edges/reconnect-edge).
